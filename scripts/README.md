# Scripts

This directory contains helper scripts for development, local smoke tests, and CI support.

| Script | Purpose |
| ------ | ------- |
| `run-backend.sh` | Build and start the local Go backend. Set `REBUILD=1` to force a rebuild. |
| `smoke-api.sh` | Check health, authenticated host listing, and an unauthenticated 401 response. |
| `build-go-android.sh` | Cross-compile the Go backend for Android arm64 into `jniLibs`. |
| `verify-apk-packaging.sh` | Verify single-ABI backend packaging, enforce an optional APK size limit, and write a contents report. |

## Environment variables

- `SSH_AI_DATA_DIR`: backend data directory, defaults to `$HOME/.ssh-ai-agent`
- `SSH_AI_PORT`: loopback listen port, defaults to `17890`
- `REBUILD=1`: force a rebuild when running `run-backend.sh`

## Generated files

The files generated by `build-go-android.sh` are ignored by Git and should not be committed:

```text
app/android/app/src/main/jniLibs/arm64-v8a/libssh_ai_agent.so
```

The Android package and build workspace contain only the `jniLibs` copy. The build also removes legacy backend copies from Android and Flutter asset directories.

GitHub Actions verifies that the APK contains exactly one `lib/arm64-v8a/libssh_ai_agent.so`, rejects legacy backend assets and unexpected ABIs, enforces 100 MiB Debug / 60 MiB Release limits, and publishes total sizes plus top-entry reports.
