# Scripts

This directory contains helper scripts for development, local smoke tests, and CI support.

| Script | Purpose |
| ------ | ------- |
| `run-backend.sh` | Build and start the local Go backend. Set `REBUILD=1` to force a rebuild. |
| `smoke-api.sh` | Check health, authenticated host listing, and an unauthenticated 401 response. |
| `build-go-android.sh` | Cross-compile the Go backend for Android arm64 and copy the binary into Flutter assets and `jniLibs`. |

## Environment variables

- `SSH_AI_DATA_DIR`: backend data directory, defaults to `$HOME/.ssh-ai-agent`
- `SSH_AI_PORT`: loopback listen port, defaults to `17890`
- `REBUILD=1`: force a rebuild when running `run-backend.sh`

## Generated files

The files generated by `build-go-android.sh` are ignored by Git and should not be committed:

```text
app/android/app/src/main/assets/go/ssh-ai-agent
app/android/app/src/main/jniLibs/arm64-v8a/libssh_ai_agent.so
app/assets/go/ssh-ai-agent-arm64
```
